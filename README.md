# jonathan-gartland.github.io

Source for my portfolio site: **[jonathan-gartland.github.io](https://jonathan-gartland.github.io/)**

I'm a software developer and senior QA engineer. The site collects my test automation and
development projects, along with my resume.

- [Projects](https://jonathan-gartland.github.io/projects/): the `mpn-lookup` npm library and
  the web and mobile apps built on it, a Next.js and ECharts app tested with Playwright, Pact
  contract testing, and API and data validation test suites
- [Resume](https://jonathan-gartland.github.io/experience/)

## Where the source is

The site is built from the **[`gh-pages`](https://github.com/jonathan-gartland/jonathan-gartland.github.io/tree/gh-pages)**
branch. This `main` branch only holds this README.

It's a [Jekyll](https://jekyllrb.com/) site using the [Minima](https://github.com/jekyll/minima)
theme, published by GitHub Pages.

## Running locally

```bash
git clone -b gh-pages https://github.com/jonathan-gartland/jonathan-gartland.github.io.git
cd jonathan-gartland.github.io
bundle install
bundle exec jekyll serve   # http://localhost:4000
```
